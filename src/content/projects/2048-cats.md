## The project

I built 2048 Cats solo for a short Game Development course. I chose a relatively simple game so I could spend time learning Unity and C# myself, while still finishing with a complete product.

## A board engine that doesn’t know about Unity

The layered architecture is the part I’m most proud of. The **core is pure C#**, with no Unity dependencies. It processes the board, resolves moves and merges, spawns tiles, calculates scores, and manages game state.

`BoardModel` holds the cells, `MoveResolver` handles sliding and merging, and `GameManager` coordinates actions, rewards, and win/loss conditions. Move results describe tile movements and merge positions so the presentation layer can animate what happened.

That boundary keeps the rules independent of scenes, GameObjects, input devices, and animation timing. Unity displays the game; it doesn’t define the board logic.

## Connecting logic to game feel

The Unity controller translates swipes and keyboard input into core actions. Views handle the board, tile sprites, score, banners, and overlays. A ScriptableObject maps tile values to artwork.

Regular moves use a bounded input queue so the player can buffer swipes while an animation is running. Power-up animations block conflicting input. Movement, merges, and power-ups each have visual feedback, with music and sound effects managed separately.

The wandering cat uses a **NavMesh agent** and animation state to bring a little life to the interface.

## Persistence outside the core

A separate persistence layer serializes the current board, score, game status, and charges to JSON in **PlayerPrefs**. Statistics and audio preferences have their own stores. The controller saves after gameplay actions and when the application pauses or quits.

This keeps Unity’s storage APIs out of the board engine while preserving progress between sessions.

My wife likes cats. I like my wife. The art direction pretty much chose itself.

She’s the potato-cat at tile 16; I’m the coding cat at 32. Before anyone does the maths: no, those aren’t our ages.
